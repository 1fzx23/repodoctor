RepoDoctor

Git 仓库健康诊断工具。扫描历史大文件、旧分支、潜在敏感信息、未跟踪文件与未提交改动，生成可读的诊断报告。

查看源码 ↗ 安装使用

功能特性

  • 综合扫描：一键运行全部诊断规则，彩色终端摘要。
  • 大文件检测：基于 git blob 大小，找出历史中的“肥胖”对象。
  • 旧分支清理：列出或删除长期未更新、且已合并的分支。
  • 敏感信息扫描：基于正则启发式，检查工作区文件中的疑似密钥、token、私钥等。
  • 工作区检查：提醒未跟踪文件、未提交改动、本地分支落后于远程。
  • 多种输出：终端彩色报告、JSON、Markdown，方便集成到 CI。
  • 零第三方依赖：仅使用 Python 标准库 + 系统 git。

诊断规则

warninglarge-blobs：历史 blob 超过阈值，可能导致 clone 变慢。
warningold-branches：分支超过阈值天数未更新。
errorsecrets：工作区文件疑似包含敏感信息。
infountracked-files：存在未跟踪文件。
warningworking-tree：工作区有未提交改动。
warningremote-sync：本地分支落后于远程。

安装与使用

git clone https://github.com/1fzx23/repodoctor.git
cd repodoctor
pip install -e .

常用命令

# 综合扫描当前仓库
repodoctor scan

# 扫描指定仓库
repodoctor -C /path/to/repo scan

# 查找大于 2MB 的历史大文件
repodoctor large-blobs -t 2

# 查找 60 天未更新的分支
repodoctor old-branches -d 60

# 扫描潜在敏感信息
repodoctor secrets

# 生成 Markdown 报告
repodoctor report -f md -o health.md

# 预览/清理旧分支
repodoctor clean
repodoctor clean -d 90 --default-branch main --yes

集成 CI

退出码 2 表示发现 warning 或 error，可轻松接入 GitHub Actions、GitLab CI 等流水线：

repodoctor scan || echo "仓库健康检查未通过"
